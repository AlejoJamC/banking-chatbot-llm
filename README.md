# banking-chatbot-llm

## Use case:
Accessing a bank chat where all your financial information is readily available, including metrics, expenses, cash flow, purchases, categories, and other typical dashboard data. The chat must be properly validated, authorized, and authenticated through prior steps. Additionally, data transmission within the chat must be carefully curated to avoid exposing sensitive financial information.

It should ensure that no information is disclosed through malicious commands, and the chat functionality must be strictly limited to read-only access. 

## Tech Stack
- Kotlin
- Spring Boot
- Spring AI
- OLlama



## Caso de uso:
Ingresar a un chat del banco y que tenga toda tu informacion financiera de acceso inmediato como tus metricas, gastos, flujo de dinero, compras, categorias, toda tipica informacion de un dashboard, y que este chat sea apropiadamente validado, autoriza y autenticado en pasos previos, ademas la transferencia de datos en el chat debe estar curada para no publicar informacion financiera critica.

Se debe validar que no revele informacion por comando maliciosos, y que tena solo funciones de lectura unicamente.
